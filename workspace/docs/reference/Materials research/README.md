# Material price research, September 2026

National-average, material-only prices as of September 2026, for M10 (F38, `docs/tasks/materials_tasks.md`). Reference only: **not loaded into any table.**

| File | What it holds |
|---|---|
| `IntelCost_material_prices_2026-10.xlsx` | The workbook. "Source points" lists every source point with its URL. "Core set (M10)" maps 109 of M10's 123 core keys |
| `material_prices_national_2026-09.csv` | The national prices, one row per material |

- **Scope:** 829 materials from 4,437 source points. No labor and no installation. For aggregates, delivered and FOB prices are kept apart.
- **Dating:** escalated to September 2026 with BLS PPI.
- **Grades:** A to F. A is 3+ public bid sources in 2+ states; F is fitted or derived.
- **Sources merged:** ChatGPT's research came in as track CG after re-verification. Gemini's was rejected because its sources could not be traced.
