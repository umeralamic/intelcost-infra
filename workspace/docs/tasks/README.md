# Task descriptions

One spec per feature in flight, named `<name>_tasks.md`, linked from the
[MANAGER.md](../../MANAGER.md) board row that tracks it.

A spec carries the full task description: the problem in detail, the subtasks
(`FN-S1`, `FN-S2`, …), the acceptance criteria and whatever the board row compresses
into two lines. The board row is the summary; this is the source.

When the feature ships, the spec moves to [../archive/](../archive/) and the feature
moves to the [FEATURES.md](../../FEATURES.md) Live table.
